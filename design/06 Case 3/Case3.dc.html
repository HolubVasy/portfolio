Case 03 · Fintech · 2026

Standard Grafana dashboards shipped with the services

Company  Fintech product company, under NDARole  Senior Developer, core services team of 5

Built one standard set of Grafana dashboards for the team's core services, kept next to the service code and shipped through the services' Helm chart, the same in every environment.

Challenge

The team lead asked me to set up observability for the processes inside each of the team's core services, six deployable processes in total. The team had dashboards, but each part was configured and delivered its own way.

Constraints

There was no common standard to build on, so the approach itself had to be agreed first. Client installations differed too. Some ran on-premises, others in Azure, so one fixed set of dashboards did not fit all of them.

Decisions
01
Dashboards next to the code, shipped with the service's Helm chart

Instead of setting dashboards up by hand and keeping their definitions in separate configuration repositories, detached from the services and their releases.

02
One template with values per environment

Instead of environment-specific values baked into each dashboard. Switching the datasource switches the environment without rewriting queries.

Results
7 dashboards in production
overview, process and runtime, logs, functional, cluster, Kafka, database, in one shared folder
About 2 months
from task to production, planned scope delivered
3 environments, one JSON
dev, test and prod run the same dashboard definitions
Takeaway

Show work early and ask for feedback sooner. Next time I would build the prototype faster and hand it over earlier.
